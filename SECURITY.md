# Security policy

## Reporting a vulnerability

Do not disclose security issues in a public GitHub issue. Use GitHub's private vulnerability reporting
for this repository or contact PropFácil through `https://www.propfacil.com/soporte` and clearly mark the
message as a security report.

Include the affected endpoint or tool, reproduction steps, expected impact and any relevant request IDs.
Do not include access tokens, passwords, personal data or third-party property-contact data in the report.

## Scope

Reports may cover the public MCP endpoint, OAuth flow, tool authorization boundaries, data exposure,
server-side request handling and the MCP Apps UI. Availability-only reports, automated scanner output
without a reproducible impact and social-engineering attempts are not eligible for a response commitment.
