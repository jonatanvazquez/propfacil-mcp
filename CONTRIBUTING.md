# Contributing

This repository accepts corrections to public metadata, installation examples and documentation. It does
not contain the production server implementation.

Before opening a pull request:

1. Do not include credentials, access tokens, personal data or unpublished property data.
2. Keep `server.json`, the deployed MCP version and `CHANGELOG.md` aligned.
3. Run the registry validation endpoint against `server.json`.
4. Verify installation instructions against a current MCP client.

Use the support page for account or listing questions and the private security-reporting path described in
[`SECURITY.md`](SECURITY.md) for vulnerabilities.
