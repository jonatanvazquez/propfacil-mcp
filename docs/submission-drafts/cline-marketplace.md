## Additional Information

PropFácil is a hosted Streamable HTTP MCP server for authorized real-estate listings in Mexico.
Search, property details, authorized contact options and structured results are public. Favorite-list
CRUD and publishing use standards-based OAuth 2.1 with PKCE. MCP Apps-compatible hosts can also render
interactive property cards, comparison and maps. No API key or local server process is required.

Endpoint: `https://www.propfacil.com/api/mcp`

Version: `1.3.8`
